# Knockout Zone

A lightweight static site for a fictional MMA-themed storefront and community hub.

## Run locally
Open the project in VS Code and use the built-in Live Preview or Simple Browser on port 5500.

## GitHub Pages
This repository is set up to deploy automatically to GitHub Pages from the main branch through a GitHub Actions workflow.

After the first workflow run, the site will be available at:
https://mewz61.github.io/wireframe-activity/
